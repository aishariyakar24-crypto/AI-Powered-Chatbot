# AI-Powered Chatbot

## Project Description

This project is an AI-powered customer support chatbot developed using Python, Flask, NLTK and SQLite.

The chatbot can understand basic user questions and provide appropriate responses.

## Technologies Used

- Python
- Flask
- NLTK
- SQLite
- HTML
- CSS
- JavaScript

## Features

- Customer support chatbot
- FAQ responses
- Natural Language Processing using NLTK
- Web-based chat interface
- SQLite conversation logging
- Responsive design

## Installation

Create a virtual environment:

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

## Run the Project

Run:

python app.py

Then open:

http://127.0.0.1:5000

## Example Questions

You can ask:

- Hello
- What courses do you offer?
- Tell me about Python
- What are the course fees?
- What are your timings?
- How can I contact you?
- Do you provide certificates?
- What payment methods do you accept?

## Database

The chatbot automatically creates a SQLite database named:

chatbot.db

The database stores:

- User messages
- Bot responses
- Date and time
